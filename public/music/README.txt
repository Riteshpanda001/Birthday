Place your romantic song file here and name it:
our-song.mp3

The website loads `/music/our-song.mp3` after the user clicks
"Open Your Surprise" on the Welcome Screen, and handles a missing file gracefully.

Optional celebration audio file:
happy-birthday-whistle.mp3
If present at `/music/happy-birthday-whistle.mp3`, this audio is played right
after the Happy Birthday vocal sequence concludes with a whistle and finger snap.
If absent, a Web Audio whistle and snap will be generated automatically.
